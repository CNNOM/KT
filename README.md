# Инструкция по добавлению файлов в приложение

## Добавление файлов в директорию `res/raw`

1. **Создайте файл**:
   - Создайте текстовый файл, который вы хотите добавить в приложение. Например, `file4.txt`.

2. **Поместите файл в директорию `res/raw`**:
   - Перейдите в директорию `res/raw` вашего проекта. Если директория `raw` не существует, создайте её.
   - Поместите созданный текстовый файл в директорию `res/raw`.

3. **Обновите `arrays.xml`**:
   - Откройте файл `res/values/arrays.xml`.
   - Добавьте имя файла (без расширения) в массив `raw_files`. Например, если вы добавили файл `file4.txt`, добавьте строку `<item>file4</item>`.

   Пример `arrays.xml`:
   ```xml
   <?xml version="1.0" encoding="utf-8"?>
   <resources>
       <string-array name="raw_files">
           <item>file1</item>
           <item>file2</item>
           <item>file3</item>
           <item>file4</item>
           <!-- Добавьте сюда имена файлов, которые вы хотите загрузить -->
       </string-array>
   </resources>
   ```

4. **Проверьте приложение**:
   - Запустите приложение.
   - Убедитесь, что новый файл отображается в списке и его содержимое загружается корректно при нажатии на элемент списка.

## Пример

Предположим, вы хотите добавить файл `instructions.txt` в приложение.

1. Создайте файл `instructions.txt` и поместите его в директорию `res/raw`.
2. Откройте `res/values/arrays.xml` и добавьте строку `<item>instructions</item>` в массив `raw_files`.

   Пример `arrays.xml`:
   ```xml
   <?xml version="1.0" encoding="utf-8"?>
   <resources>
       <string-array name="raw_files">
           <item>file1</item>
           <item>file2</item>
           <item>file3</item>
           <item>instructions</item>
           <!-- Добавьте сюда имена файлов, которые вы хотите загрузить -->
       </string-array>
   </resources>
   ```

3. Запустите приложение и убедитесь, что файл `instructions.txt` отображается в списке и его содержимое загружается корректно.
